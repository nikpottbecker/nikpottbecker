# Privacy Policy — Marker

_Last updated: 16 August 2026_

Marker is a browser extension that lets you highlight text on web pages and keep notes about it.

## What Marker stores

When you create a highlight, Marker saves the following in your browser's local extension storage (`chrome.storage.local`):

- the highlighted text and a short piece of the text before and after it, which is what lets the highlight be found again when you revisit the page
- any note you write
- the colour you chose and the time you created it
- the URL and page title of the page you highlighted, so the highlight can be restored and listed
- your settings: default colour, selection behaviour, theme, and the list of sites you have switched Marker off for

## Where it is stored

On your computer only, in the browser profile you are using. Marker does not use Chrome Sync, does not contact any server, and does not include any analytics, tracking, advertising or third-party code. The extension makes no network requests of any kind.

## What Marker does not do

- It does not collect, transmit or sell any personal information.
- It does not read pages in the background. The content script only acts on text you select or on highlights you have already saved.
- It does not touch passwords, form fields or payment details.
- It contains no remotely hosted code.

## Your control over the data

- **See it:** the side panel and the options page list every highlight you have.
- **Export it:** Markdown, plain text, or a JSON backup, from the side panel or the options page.
- **Delete it:** individual highlights, a whole page, or everything at once, from the options page.
- **Prevent it:** add a domain to the exclusion list and Marker stays inactive there entirely.
- Removing the extension deletes all of its stored data along with it.

## Chrome Web Store User Data Policy

Marker's use and handling of user data complies with the Chrome Web Store User Data Policy, including the Limited Use requirements. User data is used only to provide Marker's highlighting, note-taking, restoration, search, management, import, and export features.

Marker does not sell or transfer user data to third parties, does not use or transfer user data for purposes unrelated to Marker's single purpose, and does not use or transfer user data for creditworthiness or lending purposes.

## Contact

Questions about this policy can be sent to the developer through the extension's Chrome Web Store support page.
